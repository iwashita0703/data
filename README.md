# data

データマイニング概論などの授業で使うデータ、Rスクリプト、課題提出物をまとめたリポジトリです。

## フォルダ構成

| フォルダ | 内容 |
| --- | --- |
| `１回/` | 第1回の課題ファイル |
| `2回/` | 第2回の課題ファイル |
| `3/` - `12/` | 第3回以降の授業データ、Rスクリプト、提出物 |
| `sample/` | HTML/JavaScriptのサンプル |

各授業回フォルダには、主に次のファイルが入っています。

| 種類 | 例 | 説明 |
| --- | --- | --- |
| 授業資料 | `*.pdf` | 課題説明や講義資料 |
| 元データ | `*.csv`, `*.xlsx` | Rで読み込む分析用データ |
| Rスクリプト | `*.R`, `*.r` | 課題の実行コード |
| 提出物 | `ClassXX_rp...` | PDF、画像、PowerPointなどの提出用ファイル |

## ファイル名の見方

提出物はおおむね次の形式です。

```text
ClassXX_rp課題番号_番号.拡張子
```

- `XX`: 授業回
- `rp課題番号`: 課題番号
- `番号`: 学籍番号や出席番号など

例:

```text
Class12_rp17-6A_02.pdf
Class12_rp17-7A_02.pptx
```

## Rの実行方法

Rスクリプトは、基本的に対象フォルダを作業ディレクトリにして実行します。

```r
setwd("対象フォルダのパス")
source("kadai1.R")
```

ターミナルから実行する場合は次のようにできます。

```bash
cd 12
Rscript answers/Class12_rp17-6B_YY.R
```

## 整理ルール

- 元データは授業回フォルダ直下に置く。
- 課題の提出物は授業回フォルダ、または `answers/` にまとめる。
- Rの作業履歴やOSの自動生成ファイルはコミットしない。
- 大きく整理するときは、元ファイルを消さずにREADMEで場所を説明する。
